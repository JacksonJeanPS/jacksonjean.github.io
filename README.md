# Currículo e Portfólio — Jackson Jean

Currículo online responsivo de um profissional de **Suporte, Infraestrutura e Automação de TI**, com experiência em ambientes corporativos de alta disponibilidade.

## Problema resolvido

Centralizar experiência, certificações, competências e formas profissionais de contato em uma apresentação rápida, acessível e adequada para recrutadores.

## Demonstração

[Visualizar currículo publicado](https://jacksonjeanps.github.io/jacksonjean.github.io/)

> O projeto evita expor nomes de clientes, operações internas, telefone pessoal ou informações confidenciais.

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis, responsividade e temas claro/escuro
- JavaScript puro
- Font Awesome
- Google Fonts

## Decisões técnicas

- Site estático para carregamento rápido e hospedagem simples no GitHub Pages.
- Conteúdo renderizado em HTML para funcionar sem backend.
- Tema persistido no navegador para melhorar a experiência.
- Metadados Open Graph e SEO para compartilhamento profissional.
- Informações corporativas apresentadas de forma genérica e não confidencial.

## Executar localmente

```bash
git clone https://github.com/JacksonJeanPS/jacksonjean.github.io.git
cd jacksonjean.github.io
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Validação recomendada

- Navegação por teclado
- Contraste nos temas claro e escuro
- Responsividade em 320 px, 768 px e desktop
- Validação HTML do W3C
- Verificação de links externos
